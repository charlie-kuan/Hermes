📌 核心概念
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  愈多人走過的路徑 = GPS 軌跡密度高 = 受歡迎度分數高 = 路線規劃優先選擇


🎯 快速開始 (3 步驟)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1️⃣  準備 GPS 軌跡檔案
      └─ 放到: data/gps_traces/{area_id}/
      └─ 格式: .gpx 或 .geojson

  2️⃣  執行豐富腳本
      └─ python scripts/enrich_with_gps_traces.py

  3️⃣  啟用路線規劃中的 popularity 偏好
      └─ preferences={'popularity': 0.5}

⚙️ Blend Factor 設定
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  數值      OSM屬性    GPS軌跡    適用情境
  ──────────────────────────────────────────────────────
  0.0       100%       0%         只用 OSM 資料（預設）
  0.3       70%        30%        輕度依賴 GPS
  0.5       50%        50%        平衡模式
  0.7 ⭐    30%        70%        推薦值（GPS 為主）
  1.0       0%         100%       完全依賴 GPS

💡 使用技巧
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ✓ 至少 10-20 條軌跡才有統計意義
  ✓ 定期更新 GPS 軌跡資料（如每月）
  ✓ 混合不同來源的軌跡（OSM + 個人 + Strava）
  ✓ 調整 blend_factor 以平衡 OSM 與 GPS
  ✓ preferences['popularity'] 設 0.3-0.7 之間


🎓 進階用法
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ┌────────────────────────────────────────────────────────────────────────┐
  │ # 手動載入特定 GeoJSON                                                  │
  │ from app.core.gps_trace_processor import GPSTraceProcessor             │
  │                                                                         │
  │ processor = GPSTraceProcessor()                                        │
  │ traces = processor.load_gps_traces_from_geojson(                       │
  │     Path("data/gps_traces/yushan/my_traces.geojson")                  │
  │ )                                                                      │
  │                                                                         │
  │ processor.enrich_graph_with_trace_popularity(                          │
  │     graph, traces, blend_factor=0.8                                    │
  │ )                                                                      │
  └────────────────────────────────────────────────────────────────────────┘

  ┌────────────────────────────────────────────────────────────────────────┐
  │ # 檢查 Edge 的 GPS 軌跡數                                               │
  │ for u, v, key, data in graph.edges(keys=True, data=True):             │
  │     edge = data['data']                                                │
  │     if edge.gps_trace_count > 50:                                      │
  │         print(f"熱門路段: {edge.trail_name} - {edge.gps_trace_count}條")│
  └────────────────────────────────────────────────────────────────────────┘


🔍 疑難排解
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  問題                         解決方法
  ──────────────────────────────────────────────────────────
  找不到 GPS 軌跡             檢查目錄: data/gps_traces/{area_id}/
  豐富後分數沒變化            1. 增加更多軌跡檔案
                             2. 提高 blend_factor
  路線規劃忽略受歡迎度        確認 preferences['popularity'] > 0
  處理速度慢                  1. 減少軌跡數量
                             2. 調整 buffer_distance
