# 快速測試指南

## 啟動應用

### 1. 啟動後端 API
```bash
cd /Users/charlie/Desktop/Project/Project_Hermes

# 確保Python環境已設置
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

後端將在 http://localhost:8000 運行

### 2. 啟動前端
打開新的終端視窗：
```bash
cd /Users/charlie/Desktop/Project/Project_Hermes/frontend

# 安裝依賴（首次運行）
npm install

# 啟動開發伺服器
npm run dev
```

前端將在 http://localhost:5173 運行

## 測試新功能

### 測試案例 1：玉山主峰路線
1. 開啟 http://localhost:5173
2. 選擇區域：**玉山群峰**
3. 選擇路線：**玉山主峰單攻/二日**
4. 觀察地圖上自動顯示的登山口和waypoints
5. 勾選 "排雲山莊" 和 "玉山主峰"
6. 點擊「規劃路線」
7. 查看右側面板的詳細資訊
8. 點擊「匯出 GPX」下載路線檔案

### 測試案例 2：合歡山一日遊
1. 選擇區域：**合歡山群峰**
2. 選擇路線：**石門山步道**（最簡單）
3. 保持預設選項
4. 點擊「規劃路線」
5. 查看估計時間（約1小時）
6. 導出 GPX 檔案

### 測試案例 3：合歡主東峰連走
1. 選擇區域：**合歡山群峰**
2. 選擇路線：**合歡主東峰連走**
3. 兩座山頭都應該被自動選中（必經點）
4. 設定體能水平為「專家」
5. 點擊「規劃路線」
6. 查看多日規劃（如果有）

### 測試案例 4：雪山經典路線
1. 選擇區域：**雪山主峰、東峰**
2. 選擇路線：**雪山主東峰線**
3. 勾選想要的waypoints
4. 設定為「多日行程」
5. 點擊「規劃路線」
6. 查看過夜點安排

2. **座標可能需要調整**：某些waypoints的座標是估算值

## 疑難排解

### 問題：地圖無法顯示標記
**解決**：檢查 MapComponent.jsx 是否正確接收 selectedRoute 和 selectedWaypoints props

### 問題：選擇路線後沒有自動填充起點
**解決**：檢查 RouteForm.jsx 中的 useEffect 是否正確觸發

### 問題：無法導出 GPX
**解決**：
1. 確認後端 API 正在運行
2. 檢查瀏覽器控制台的錯誤訊息
3. 確認 route_id 存在於後端快取中

### 問題：waypoints 無法勾選/取消
**解決**：檢查 required 屬性，必經點無法取消是正常行為
