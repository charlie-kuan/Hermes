# 新功能說明 - 路線選擇與規劃系統

## 🎯 概述

網站已經更新為更符合登山路線規劃的流程：
1. **選擇山區** → 2. **選擇預設路線** → 3. **選擇經過點** → 4. **生成詳細路線和GPX**

## ✨ 新功能

### 1. 預設路線選擇
- 每個山區現在包含多條預設路線
- 路線包含詳細資訊：
  - 登山口位置（自動設為起點）
  - 必經山頭和山屋
  - 可選擇的waypoints
  - 預估天數、距離和時間
  - 難度等級

### 2. Waypoints 管理
用戶可以選擇想要經過的地點：
- 🚩 **登山口**：自動作為起點，不可取消
- ⛰️ **山頭**：可選擇想攻頂的山峰
- 🏠 **山屋/住宿點**：可選擇過夜地點
- 📍 **中繼點**：其他重要地標

#### Waypoint 狀態
- **必經點**：標示為"必經"，無法取消勾選
- **可選點**：可以自由勾選或取消

### 3. 地圖預覽
- 選擇路線後，地圖會立即顯示：
  - 登山口（綠色標記）
  - 選中的山頭（橘色標記）
  - 選中的山屋（紫色標記）
  - 其他waypoints（黃色標記）

### 4. GPX 檔案導出
規劃完成後可以導出詳細路線：
- **GPX 格式**：可匯入GPS裝置或登山App
- **GeoJSON 格式**：可用於地圖分析
- 包含完整的航跡點和waypoints資訊

## 📝 使用流程

### 步驟 1：選擇山區
在左側面板選擇想要登山的區域，例如：
- 玉山群峰
- 合歡山群峰
- 雪山主峰、東峰
- 等等...

### 步驟 2：選擇路線
選擇山區後，會出現該區域的預設路線選項，例如：
- **玉山主峰單攻/二日** (2天 - 困難)
- **合歡主東峰連走** (1天 - 中等)
- **雪山主東峰線** (2天 - 困難)

選擇後會顯示：
- 路線描述
- 預估距離和時間
- 建議天數

### 步驟 3：選擇經過點
系統會顯示路線上的所有可選地點：

```
🚩 塔塔加登山口 (起點)
   登山口 | 2610m
   [自動選擇，不可取消]

☑️ 排雲山莊 (必經)
   山屋 | 3402m | 住宿, 廁所, 用水
   
☐ 玉山主峰
   山頭 | 3952m
```

勾選想要經過的山頭和住宿點。

### 步驟 4：設定個人參數
- **體能水平**：初學者/中等/專家
- **背包重量**：影響時間估算
- **其他偏好**：多日行程、避開困難路段等

### 步驟 5：規劃路線
點擊「🗺️ 規劃路線」按鈕，系統會：
1. 計算最佳路線
2. 估算行進時間
3. 安排多日行程（如適用）
4. 提供裝備和食物建議

### 步驟 6：查看結果與導出
右側面板會顯示：
- 📊 **基本資料**：總距離、爬升、下降、難度
- ⏱️ **時間估算**：樂觀/正常/保守三種時間
- 📅 **多日規劃**：每日行程和過夜點
- 🎒 **裝備建議**：必備裝備清單
- 🍽️ **食物與水**：建議攜帶量

點擊導出按鈕可下載：
- **GPX 檔案**：匯入Garmin、Suunto等GPS裝置
- **GeoJSON 檔案**：用於其他地圖應用

    "lat": 23.4690,

## ❓ 常見問題

**Q: 可以不選擇預設路線，自己標記嗎？**
A: 可以！如果不選擇預設路線，仍可在地圖上自行點擊起點和終點。

**Q: 為什麼有些waypoints無法取消？**
A: 標記為"必經"的點是路線規劃中必須經過的重要地點，如山屋或關鍵山頭。

**Q: GPX檔案可以用在哪些裝置？**
A: 可用於Garmin、Suunto、Coros等GPS手錶，以及健行筆記、綠野遊蹤等登山App。

**Q: 時間估算準確嗎？**
A: 系統提供三種估算（樂觀/正常/保守），會根據體能水平、背包重量、地形難度等因素計算。建議以"保守"時間為準。
